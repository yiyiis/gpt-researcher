# Data-Driven Decisions

## Overview
Good decisions come from rigorous data interpretation, not cherry-picked evidence. Apply quantitative methods and actively counter your own biases.

## When to Use
- Comparing products, technologies, or strategies with data
- Evaluating claims that need quantitative backing
- Research where objectivity is critical (investments, technical evaluations)
- Any time you're tempted to state "X is better than Y"

## Core Principles

### Quantify, Don't Qualify
- Replace "much faster" with "3.2x faster (measured by X)"
- Replace "more popular" with "62% market share vs 18%"
- If you can't measure it, say so explicitly

### Avoid Common Cognitive Biases
| Bias | Trap | Antidote |
|------|------|----------|
| Confirmation | Seeking only supporting evidence | Actively search for disconfirming data |
| Survivorship | Ignoring failures | Ask "what didn't make it into the dataset?" |
| Recency | Overweighting recent events | Establish baseline trends over time |
| Anchoring | Latched to first number | Derive estimates independently first |

## Comparison Framework
When comparing options A vs B:
1. Define evaluation criteria upfront (before looking at data)
2. Weight each criterion by importance
3. Score each option per criterion
4. Calculate weighted totals
5. Sensitivity-check: does the winner change if weights shift?

## Data Quality Checklist
- Source: primary vs secondary? Recency?
- Methodology: how was it measured?
- Sample: size and representativeness
- Conflicts: does other data corroborate?

## Common Mistakes
- Presenting correlation as causation
- Using a single data point as "evidence"
- Ignoring confidence intervals or margins of error
- Reporting precision that exceeds the data's accuracy
